# 后端目录路由

- **后端结构或实现：** 先读 `docs/architecture/backend-cleanddd-netcorepal-guidelines.md`。
- **HTTP endpoint、Gateway 或契约：** 先读 `docs/architecture/api-contract-and-codegen.md` 与 `docs/architecture/facade-coverage-matrix.md`，并按其中的完成定义执行。
- **schema 或 migration：** 先读 `docs/architecture/database-schema-conventions.md`、`docs/architecture/database-schema-catalog.md` 与 `docs/architecture/database-release-runbook.md`。
- **时间、等待、网络、全局状态、隔离或 determinism baseline 测试：** 先读 `docs/architecture/backend-test-determinism.md`。
- **验证：** 从受影响的 solution/project 和上述权威文档取得命令。
