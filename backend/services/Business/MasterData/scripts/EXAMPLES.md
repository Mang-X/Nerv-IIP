# 历史示例说明

本文件曾包含模板时代的基础设施示例，现已收缩为历史指针。原示例与 Nerv-IIP 当前的 PostgreSQL、Aspire 和受治理脚本基线冲突，因此不受支持，也不得执行或复制。

尤其不得从旧版本中沿用 MySQL/Kafka 默认值、直接 Docker Compose 或 `dotnet run` 启动方式、默认凭据、模板连接串和逐服务基础设施拓扑。

当前开发、验证与排障入口以[同目录说明](README.md)、[仓库根目录 `nerv.ps1`](../../../../../nerv.ps1) 以及[根目录受治理脚本](../../../../../scripts/)为准。
