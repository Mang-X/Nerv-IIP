# 工厂设定与人工走查最小数据

本文是工厂设定与人工走查数据的当前权威来源。历史形成过程保留在
[`2026-07-26-factory-world-bible.md`](../../superpowers/plans/2026-07-26-factory-world-bible.md)，
该文件是不可改写的 Superpowers 历史快照；后续设定与走查数据调整只修改本文及其代码投影。

## 1. 目标与边界

人工走查必须能在不依赖大规模背景历史的干净本地环境中完成 ERP 采购链和销售链。最小数据只提供：

- 可选择的结构性主数据；
- 一套可人工复算的采购价与销售价；
- 一个成品的 BOM、工艺路线、生产版本和工时定额；
- 可继续转业务单据的询价、供应商报价和销售报价起点。

最小数据不创建采购订单、收货、销售订单、发货、应收应付、凭证、库存余额或生产结果。
这些结果必须由走查者通过公开业务路径产生，避免页面非空被误报为真实流程通过。

## 2. 工厂基线

- 组织：`org-001`；环境：`env-dev`；厂区：`SITE-001`（一号工厂，`Asia/Shanghai`）。

- 结构：3 个车间、14 条产线、17 个工作中心；最小投影保留该结构以承载完整八道工序，
  但不写入全量 46 台设备和 58 名员工。

- 全量设定仍采用 84 SKU、8 客户、10 供应商以及 L0/L1/L2/L3 分层；它只用于需要整厂背景的
  专项场景，不再是日常人工走查的前置。

### 活塞杆自制工程输入

`SF-ROD-01`（活塞杆 φ20×380，产出单位 `pcs`）另有独立 V1 EBOM、MBOM、路线与默认生产版本，
自 2026-01-05 生效、无失效日期。它允许本次单据选择自制，SKU 仍可外购。
唯一组件是最小目录已有的 `RM-BAR-01`（45# 钢棒料 φ22，`kg`）；不存在半成品自引用或成品反向需求。

工程设定以 **1 件合格活塞杆消耗 1.40 kg 棒料毛重** 为人工走查定额，EBOM 和 MBOM 均按该毛重建模。
这是本场景的计划投入，包含切断余料和机加工去除量，不是供应商报价数量反推的工程需求。
作为尺寸复核，场景采用密度假设 7850 kg/m³：φ20×380 的圆柱包络质量为
`π × 0.010² × 0.380 × 7850 ≈ 0.9372 kg`，投入与包络质量之差约 `0.4628 kg`，留给毛坯余量、
切断和加工损失。该简化定额不声明材料标准符合性，也不代替客户图纸或现场工艺认证。
毛重已含工艺损失，因此 MBOM 的 `scrapRate=0`、`yieldRate=1`；产出 N pcs 的原料需求为
`N × 1.40 × (1 + 0) / 1 = 1.40N kg`，不得再叠加同一损失。

路线按顺序复用已有 `OP-WB-CUT / WC-TUB-01`、`OP-WB-CNC / WC-ROD-01`、
`OP-WB-GRD / WC-GRD-01`。准备/单件运行/收尾分钟分别为 `15/2/5`、`20/6/5`、`12/4/4`；
批量 N 件的工序时间依次为 `20+2N`、`25+6N`、`16+4N`，一件合计 73 分钟。
三道工序均要求报工、非外协；它们只完成本最小工程路线，不新增镀层、热处理或采购/库存结果。
代码投影由 ProductEngineering 的 `WalkthroughSeedSpec` 与 `WalkthroughRodSeedService` 持有，
公开版本标识为 `EBOM-SF-ROD-01:1`、`MBOM-SF-ROD-01:1`、`ROUTING-SF-ROD-01:1`。

## 6. 启用与隔离

本地 AppHost 默认向 MasterData、ProductEngineering 和 ERP 注入
`Walkthrough:Seed:Enabled=true`。单次会话可用 `NERV_IIP_WALKTHROUGH_SEED=false` 关闭。
三个服务只允许在 `Development` 环境执行；重复执行幂等，同号保留事实不兼容时失败且不覆盖。

最小投影与 `LeaderDemo:World:*`、`LeaderDemo:History:*` 独立。验收时必须关闭旧全量世界和历史，
并用 `*-WALK-*` 业务编号与本节明确的主数据编码取证，避免旧数据造成非空假阳性。

## 7. 走查与前置核对

1. 在隔离真栈中关闭全量世界、背景历史和规模块，保留最小投影。
2. 采购链从 `RFQ-WALK-001` 的供应商报价创建采购订单，经审批下达、收货与入库；采购订单、

4. 页面证明必须同时包含真实 GET 200、稳定业务编号行和空态文案未出现；单元测试或 API 成功
   不能代替真浏览器页面证据。
