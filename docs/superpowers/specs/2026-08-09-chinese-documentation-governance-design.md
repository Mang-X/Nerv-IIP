# 全仓中文文档治理设计

## 目标

将 Nerv-IIP 仓库内所有人工编写的文档统一为中文，并建立持续生效的语言治理规则。治理同时覆盖仓库外的 Linear 协作文本：项目、Issue、评论、审核结论及其他面向团队的说明默认使用中文。

## 治理范围

纳入以下受版本控制的人工文档：

- 根目录及各子目录的 `README.md`、`AGENTS.md`、`CLAUDE.md`、设计说明和产品说明；
- `docs/architecture/`、`docs/adr/`、`docs/demo/` 下的架构、决策和演示文档；
- `docs/superpowers/plans/` 与 `docs/superpowers/specs/` 下的历史计划和设计规格；
- `frontend/DESIGN/`、设计系统组件文档和产品文档；
- 人工维护的 Copilot 指令、Skill 文档和脚本使用说明。

以下内容不做翻译，但必须在最终清单中标明排除理由：

- 测试夹具、日志、运行证据、指纹、快照和协议样本；
- 由工具生成且禁止手工编辑的文件；
- 必须保持字节稳定或作为程序输入解析的文本。

初始盘点基线为 571 个文档型文件，其中 569 个 Markdown 文件、2 个文本文件，共约 105,974 行。最终验收必须从 Git 重新生成清单，不能把该数字当作静态真值。

## 中文化规则

人工叙述内容必须使用简体中文，包括：

- 文档标题、章节标题、说明段落、步骤、注意事项和验收结论；
- 表格中表达业务含义、规则、状态或操作说明的文字；
- 代码块之外的示例解释、审查意见和维护说明；
- AGENTS、CLAUDE、Copilot 和 Skill 指令中的自然语言要求。

以下内容允许保留原文：

- 代码、命令、路径、文件名、URL、版本号和正则表达式；
- API、类型、方法、变量、配置键、协议字段和数据库标识符；
- 产品名、库名、标准名、缩写及缺乏稳定中文译名的专业术语；
- 为保持可搜索性而保留的英文术语，但其所在句子的解释必须使用中文。

翻译不得改变需求强度、状态、数字、日期、边界条件、命令语义、代码围栏、链接目标或表格结构。`MUST`、`SHOULD` 等规范性词汇可译为“必须”“应当”，但不能弱化语义。

## AGENTS 与 Linear 协作规则

根 `AGENTS.md` 增加全局语言治理章节，并由子目录 `AGENTS.md` 自动继承。规则必须明确：

1. 所有新增或修改的人工文档默认使用简体中文；
2. 代码、命令、标识符、配置键和必要专业术语可以保留原文；
3. Linear 中的项目名称与说明、Issue 标题与正文、评论、审核意见、状态说明、验收记录和复盘结论默认使用中文；
4. 引用外部英文原文时可保留短引文，但必须提供中文上下文或中文结论；
5. 不得翻译机器输入、生成文件或需要保持原样的证据内容。

## 实施架构

控制代理只负责清单、分区、任务台账、冲突协调和最终验收，不与实施代理混合修改。实施任务按互不重叠的目录切分：

1. 根目录、`.claude/`、后端说明、基础设施、Skills、`docs/architecture/` 与 `docs/adr/`；
2. `docs/superpowers/plans/`；
3. `docs/superpowers/specs/`；
4. `frontend/DESIGN/`、产品文档、设计系统文档及前端子树指令。

受并发槽位限制，任务分多轮执行。同一轮中的代理不得修改相同文件。每个实施任务完成后由独立复核代理检查翻译完整性、技术语义和格式；实施者不得审核自己的结果。

## 闭环扫描

每轮结束后重新扫描全部候选文档，重点检查：

- 代码围栏外没有中文上下文的英文标题；
- 代码围栏外连续英文叙述段落；
- 表格中的英文业务说明；
- AGENTS、CLAUDE、Copilot 和 Skill 指令中的英文自然语言；
- 未登记原因的排除文件；
- 翻译造成的围栏、链接、锚点、表格或规范性语义损坏。

扫描结果分为“必须翻译”“合法保留”“机器输入排除”三类。只有“必须翻译”清单归零，并且合法保留项经过人工抽查后，才能结束治理循环。

## 验证与完成条件

完成前必须取得以下新鲜证据：

1. 从 Git 重新生成的文档总清单及分类统计；
2. 英文标题和英文叙述扫描中没有未裁定的命中；
3. 所有根级与子目录 `AGENTS.md` 均未削弱全局中文规则；
4. Markdown 围栏、内部链接、相对路径和表格结构检查通过；
5. `git diff --check` 通过；
6. 若新增或修改治理脚本，`scripts/check-script-governance.ps1` 通过；
7. 独立全分支复核没有未处理的严重或重要问题。

本任务不修改业务代码、公开契约、数据库、生成客户端或机器证据，也不执行推送、创建 PR 或修改 Linear 数据。
