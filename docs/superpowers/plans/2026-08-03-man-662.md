# MAN-662 Deterministic Backend Test Infrastructure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace timing guesses, platform-default network timeouts, and order-dependent process globals in the default backend PR lane with deterministic clocks, bounded diagnostic waits, explicit network outcomes, and repository-governed restoration or process isolation.

**Architecture:** Extend the existing narrow `Nerv.IIP.Testing` library with clock-aware `Eventually`/timeout/diagnostic contracts, a bounded CAP-host bootstrap wait, and a scope for globals that actually expose restorable public state. Migrate one representative path in Maintenance, Inventory, Ops, and IndustrialTelemetry; remove Inventory's static Prometheus collectors by injecting a registry. FastEndpoints 8.1.0 keeps getter-only `Config` children in static readonly fields and exposes no public replacement setter, so its serializer/validation/discovery mutations stay in serialized service collections and a sacrificial test project whose testhost process exits after deliberate mutation. A static checker governs remaining timing/global-state exceptions, while a separate no-TRX verifier proves seeded order and xUnit concurrency stability.

**Tech Stack:** .NET 10, xUnit 2.9.3, `xunit.runner.visualstudio` 3.1.4, `Microsoft.Extensions.TimeProvider.Testing` 10.8.0, FastEndpoints 8.1.0, FluentValidation 11.x, `WebApplicationFactory`, PowerShell 7, GitHub Actions.
