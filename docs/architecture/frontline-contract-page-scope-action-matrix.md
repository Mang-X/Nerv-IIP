# 现场作业契约—页面—范围—动作事实矩阵

本文是 MAN-620 / GitHub
[#1157](https://github.com/Mang-X/Nerv-IIP/issues/1157) 的仓库事实盘点，覆盖
MES、WMS、Quality、Maintenance、设备报警、Business PDA、Business Console
以及规划中的工位机、车间机表面。它回答“当前公开契约和页面实际能做什么”，不把类型名、
页面按钮、HTTP 200 或组织级列表推断为已经具备个人任务、完整生命周期或可执行动作。

### 1.2 作业范围口径

MAN-619 / GitHub
[#1156](https://github.com/Mang-X/Nerv-IIP/issues/1156) 尚未合入仓库文档，因此本文只采用其
任务简报约束的五级定义，不复制未合入分支内容：

| 范围           | 本文判定标准                                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `Self`         | 服务端以已认证当前 principal 验证 assignment/ownership 后过滤；前端传任意 user ID、页内筛选或行上恰好出现本人 ID 均不算。 |
| `Team`         | 服务端从当前主体的有效班组成员关系裁决，不信任客户端自行声明 team。                                                       |
| `WorkCenter`   | 服务端验证请求的工作中心属于当前主体授权范围。仅有 `workCenterId` 查询参数不等于已实现该裁决。                            |
| `Workshop`     | 服务端验证请求的车间属于当前主体授权范围。                                                                                |
| `Organization` | 只以 `organizationId + environmentId` 为硬 scope 的组织业务队列；它不是“我的任务”。                                       |

| 标签        | 含义                                                                           |
| ----------- | ------------------------------------------------------------------------------ |
| **当前**    | 当前公开契约和页面已有可验证事实。                                             |
| **P0 缺口** | 会造成错对象写入、伪个人任务、终态误操作、重复写或不可信成功回执，必须先收口。 |

| **待裁决**  | 产品/交互/共享协议需由归属 issue 决定，本文不替实现 issue 定设计。             |

## 2. 横切契约事实

### 2.1 当前授权、错误和回执

- Gateway 每请求先校验 bearer、`organizationId + environmentId` 和 operation
  permission；401/403 是当前公开授权边界。前端按 permissionCodes 隐藏入口只属于 UX，
  不能替代 Gateway 裁决。
- 通用代理会保留下游非 2xx 状态码，因此真实下游 409/422 可以透传；但本矩阵涉及的
  OpenAPI operation 当前普遍只声明 200、400、401、403，MES 多数 operation 甚至未声明
  400。2xx 且 `success:false` 的下游响应会被统一转成 400。
- 当前没有跨域统一的 `OperationReceipt`。各命令返回各自的强 ID、状态或
  `accepted`；HTTP 200、本地 toast、乐观状态和 `accepted` 字段本身不能替代对应业务对象
  的权威回读。
- 下游 payload 无法解析时 Gateway 返回 502 `downstream-invalid-response`；前端不得把旧行、
  默认值或上次成功结果展示为本次成功。
- 统一 401/403/404/409/422/5xx、幂等键生命周期和权威回执由
  [#1162](https://github.com/Mang-X/Nerv-IIP/issues/1162) 负责；跨端回执组件和错误协议由
  [#1172](https://github.com/Mang-X/Nerv-IIP/issues/1172) 负责。

### 2.2 `allowedActions` 与阻塞原因现状

- OpenAPI/generated DTO 中没有任何 `allowedActions` 或标准 `blockReasons` 字段。
- MES 工单详情返回 `blockingReasons`，MES dispatch 行也返回 `blockingReasons`；这是已有
  阻塞事实，不等同于跨域动作许可。
- WMS、Quality、Maintenance、设备报警列表/详情均没有服务端动作清单或标准阻塞原因。
- 当前页面按本地 status switch、权限码或按钮可见性判断动作，状态缺失/未知时必须 fail
  closed。全端终态、未知态、冲突态统一门禁归
  [#1160](https://github.com/Mang-X/Nerv-IIP/issues/1160)，共享 `ActionGate` 协议归
  [#1172](https://github.com/Mang-X/Nerv-IIP/issues/1172)。

## 5. 前端真实呈现要求

1. 当前没有任何上述列表达到服务端 principal-bound `Self` 口径。
   `listBusinessConsoleMesDispatchTasks(assignedUserId=currentPrincipalId)` 仍只是客户端可控参数，
   必须显示“组织/业务范围待办”及查询来源；伪“我的任务”纠偏归
   [#1163](https://github.com/Mang-X/Nerv-IIP/issues/1163)，真正的当前主体查询归
   [#1164](https://github.com/Mang-X/Nerv-IIP/issues/1164)、[#1165](https://github.com/Mang-X/Nerv-IIP/issues/1165)。
2. 页面必须同时显示后端 `total`、已加载数、筛选条件和更新时间。不能以固定 `take=100/200`
   冒充全量；统一移动列表壳和分页恢复归
   [#1171](https://github.com/Mang-X/Nerv-IIP/issues/1171)。
3. 缺 org/env 或后续 required scope 时不发空 ID 请求；没有 assignment 支持时不得拉全量后
   在前端伪造 Self。
4. 列表与动作必须沿同一组强 ID：MES 报工尤其固定
   `workOrderId + operationTaskId`；路由切换、慢请求和返回不得把旧对象回写到新页面。归
   [#1159](https://github.com/Mang-X/Nerv-IIP/issues/1159)。
5. Completed、Cancelled、Closed、Cleared 和未知状态默认只读。提交前刷新/重核当前状态；
   409 后刷新详情并撤销操作区。前端隐藏不是服务端安全边界。归
   [#1160](https://github.com/Mang-X/Nerv-IIP/issues/1160)。
6. 成功结果只展示服务端回执中的业务 ID/编号；`accepted=true`、HTTP 200 或本地 toast 之后，
   若契约没有终态回执，继续回读权威对象。
7. `dataFreshness=unavailable`、空 telemetry history、空 maintenance history 显示“暂无数据/
   历史数据积累中”，不得渲染默认健康结论或补造维修记录。
8. 人员、设备、工位、库位、批次、原因码和优先级应来自可搜索目录，不要求一线用户手输
   GUID；目录归 [#1169](https://github.com/Mang-X/Nerv-IIP/issues/1169)，PDA 高频输入先由
   [#1161](https://github.com/Mang-X/Nerv-IIP/issues/1161) 收口。
