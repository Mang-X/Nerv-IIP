## 盘点结论

在 commit `27122126f026d0c947fc1d448ce654fe8b060b6c` 上，按类名包含 `WorldHistory`、`WorldBible` 或 `LeaderDemoScale` 的测试做闭合枚举，共覆盖 **14 个程序集、46 个类、290 个测试方法、510 个展开实例**。本机 Release 实测得到 **497 个通过、13 个未执行、0 个失败**；13 个未执行实例全部需要 `NERV_IIP_TEST_POSTGRES`，且与 `scripts/postgres-test-lane.json` 的 `scaleSeedExemptions` 一一对应，不能把它们约 1 ms 的环境门耗时当作全规模预算证据。
