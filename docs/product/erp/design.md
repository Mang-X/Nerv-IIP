# ERP 财务成本读面

## 机器制造费用

财务人员在财务菜单的“机器制造费用”中，按工单核对机器实绩工时与固定、变动预定分配额；按会计期间核对工作中心月度实际费用池、已分配额和未／多分配差异。

- 工单金额是按冻结费率计算的预定分配，不代表已核定实际机器成本。工序明细保留费率期间、费率版本、结算编号与版本、来源事件和完成时间，支持复核结算来源。
- 月度差异为实际费用池减已分配额：正数为未分配，负数为多分配，零为无差异；各行明确币种，不跨币种合计。
- 可用、不适用、不可用分别呈现，不可用原因转成业务文案；明确零显示数值零。冲销后按重新读取的有效结算呈现，未重新结算时显示不可用，不沿用旧金额。
- 工作中心月度记录可包含历史版本；已被替代或需要重新对账的记录保留状态与原因，其金额仅供历史核对，不表述为可用于关账的当前结论。
- 本读面不提供费率配置或月末关账操作。
