# 条码标签

## 控制台确认待打印

具备正式打印权限的条码操作员在“打印批次”创建批次，服务端先预留标签，列表和详情显示“已预留”。选中批次后，在详情点击“确认待打印”；确认成功后重新读取服务端状态，显示“待打印”。请求期间按钮禁用；失败通过操作提示反馈，状态仍以服务端回读为准。

确认是独立业务动作，不创建 MES 报工、不填写生产上报身份。MES 激活保留真实生产上报身份要求。只有已预留批次可确认；发送仍只允许待打印或打印失败批次，确认本身不表示已发送或已打印。完成状态回读属于后续打印流程。

## 选择打印机并发送

待打印或打印失败批次在详情提供“发送打印”。操作员从可搜索的打印机目录选择已启用打印机，目录来自服务端正式配置，仅展示名称与标识，不提供传输地址或超时配置。开发环境正式配置的模拟打印机同样从此目录选择。

选择后点击发送，请求期间禁用重复提交。发送结束重新读取列表与详情，成功提示“打印批次已发送”，状态以服务端回读为准；失败通过操作提示反馈，具体批次状态与失败原因以服务端回读为准。传输送达待核实的批次不能再次发送。发送成功不表示已打印，只有服务端完成事实才能显示已打印。

## 模板资产退役

具备模板资产退役权限的管理员从“标签模板”当前模板行进入“资产退役”。先停用模板，再核实模板名称、填写原因并确认。服务端负责判断资产是否仍被引用；前端不替代这一判断。普通模板维护权限不会授予资产退役操作。

确认后显示“已受理”，刷新只查询既有结果。请求结果未确认时保留原提交内容，再次确认使用同一幂等请求；已存在裁决时只展示状态，不再次执行。

| 服务端事实 | 用户看到的状态 |
| --- | --- |
| pending | 处理中 |
| quota-released | 配额已释放，文件仍保留 |
| execution-outcome-unknown | 执行结果待核实，已暂停 |
| replay-window-expired | 查询窗口已过期 |

配额释放不表示文件已物理删除。执行结果未知和查询窗口过期均不提供重新执行、清除或解除暂停操作。请求失败是本次操作反馈，不是新增的持久退役状态。

基础入口限当前模板及当前文件，不承诺换绑后的永久历史视图；不依赖执行明细账本，不显示内部签名、校验摘要、对象键或服务端敏感原因。操作权限及真实数据仍由公开门面逐次核验。

## 仓储收货来源选择

入库单来源选择器搜索本次入库读取权限下全部授权工厂的真实单据，包括未分配和分配给其他人的入库单；选中值为正式入库单号。搜索不依赖、也不改变 WMS 入库页记住的作业范围。入库页及仓储执行操作继续使用原作业范围与写权限。

## 开发模拟打印完成

已登记开发模拟打印机执行本次批次的编译标签后，服务端记录同一作业和批次的完成事实。列表及详情显示“已打印”，详情显示服务端保存的打印时间，标签明细保持该批次的标签值并显示已打印。刷新页面后仍回读这些事实。模拟完成只证明开发模拟作业完成；普通发送和真机 ZPL 传输成功仍只表示已发送。
