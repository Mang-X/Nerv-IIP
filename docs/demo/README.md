## 怎么用

**先读手册的 §0「演示前必读」再动手。** 那一节的每一条都是实测踩出来的，尤其：

1. 起栈必须 `nerv.ps1 demo`，**不能** `nerv.ps1 dev`（后者不激活演示世界种子，第 1 棒就走不下去）
2. 单号日期跟随演示世界的 `asOfDate`，不是操作系统当天
3. 只用 `WO-2026-*` 号段的工单
4. 手册里标「现场不要点」的几处，是第三轮实测必失败的

## 手册的状态标注

每章开头写明该章**第三轮有没有真机重走**：

- 未标注 = 第三轮实测重走过，步骤与截图都是当轮的
- 标「沿用第二轮」= 步骤仍可信（数据同种子），但未在第三轮栈上逐步复核

这个区分是刻意保留的——**没有真机结论就不改手册**，否则手册会变成编造。

## 为什么截图不是"有就贴上"

第一版曾把三轮走查的截图（第一轮 20 + 第二轮 75 + 第三轮 33）混在一起贴进手册。这是错的：

- 不同轮次的界面、数据、单号都不一样，读者照着做会对不上
- 更糟的是，其中若干步骤在拍摄当时**并没有走通**——把卡住的界面当成操作示范，
  等于教人走一条走不通的路

操作手册的截图必须来自**同一次、全程走通**的走查。
