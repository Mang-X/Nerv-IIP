## 怎么用这份手册

**先读 §0「演示前必读」再动手。** 那一节每条都是实测踩出来的，其中几条会直接决定演示成败：

1. **起栈必须 `nerv.ps1 demo`，不能 `nerv.ps1 dev`** —— 后者不激活演示世界种子（业务伙伴 0、物料 0、MES 工单 0），第 1 棒在「选客户」就走不下去
2. **单号日期跟随演示世界的 `asOfDate`**，不是操作系统当天
3. **只用 `WO-2026-*` 号段**的工单（`WO-SCALE-*` 与 `WO-DEMO-Q01` 逐工序按钮全被拦，见 #1385）
4. **排产别现场随手勾单**：只用 E1/S2 平台的固定组合，且**别超 10 张**（14 张耗时 9.61s，网关 10s 超时）
5. **不要现场重跑 MRP**：种子里的建议是预置的，重跑读全厂库存实况、结果与它无关。走「查看已有 MRP 运行 → 接受建议」
6. **`fullstack` 会话默认租约 90 分钟**，过期 guardian 会自动拆栈。演示前用 `NERV_IIP_FULLSTACK_LEASE_MINUTES` 加长，或挂续租心跳

## 手册的可信度标注

每章开头写明该章**是否在最后一轮真机重走过**。标「沿用上一轮」的章节步骤仍可信（数据同种子），但未在当前栈上逐步复核。

**没有真机结论就不改手册**——否则手册会变成编造。
