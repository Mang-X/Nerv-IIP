# ADR 0036：永久保留 DHTMLX Evaluation 试用版

- 状态：已接受 — 落盘既有 owner 裁决
- 日期：2026-10-23

## 背景

排程可视化使用 DHTMLX Gantt Professional Evaluation。仓库已跟踪 `frontend/packages/scheduling/vendor/dhtmlx/` 下的 JS、CSS 与类型声明，文件头保留厂商 Evaluation 许可声明。

[议题 #1757](https://github.com/Mang-X/Nerv-IIP/issues/1757) 曾要求在购买许可、移出仓库、更换引擎之间裁决；[议题 #1270](https://github.com/Mang-X/Nerv-IIP/issues/1270) 的既有说明仍留有商业部署时替换的表述。owner 已在本次实施会话中重申既有决定：

> 不存在有商业部署的行为，所以永久保留
>
> 这个之前早就裁决过了，这个库中始终使用使用版，不会涉及商业行为，无需更换任何，无需移除

上下文中的“使用版”指现有 Evaluation 试用版。本记录将这一最终裁决落盘，不新增采购或引擎演进决定。

## 决策与理由

本仓库无商业部署、不涉及商业行为，永久保留并持续使用现有 Evaluation 试用版，不更换、不移除。试用版不是等待商业包或自研引擎的过渡状态；不设置采购、自研或换引擎承诺。

保留现有 vendor、厂商许可声明、Evaluation 提示与水印，以及现有适配器、加载选择和缺包回落行为。本决定记录 owner 对本项目用途与保留路线的裁决，不构成对厂商许可有效性或授权范围的法律结论。

## 已考虑的替代方案

- **购买或替换商业授权包**：owner 明确本仓库无商业部署、不涉及商业行为，未选择采购或替换路线。
- **移出或删除 Evaluation vendor**：与“永久保留”“无需移除”的裁决相反，不采用。
- **更换第三方引擎或最终自研**：与“无需更换任何”的裁决相反，不采用，也不作为后续承诺。

## 后果与复评边界

当前 README 与 Product 说明应与永久保留路线一致，删除商业许可已持有、试用包未入 Git、待移除及后续替换承诺等矛盾文字。历史议题评论保留时点语义，不作为本裁决的现行替代。

本决定无到期日，不因版本迭代、产品化进度或旧票中的商业包/自研计划自动复评。只有 owner 明确改变本裁决时，才通过新的决策记录说明取代关系；这不预设任何采购、商业部署或换引擎安排。

本记录不改变排程计算边界、产品功能或运行行为，不新增发布机制，也不通过修改 vendor、CSS 或水印实施本决定。
