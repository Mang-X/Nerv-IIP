# 纵切阶段历史

本目录冻结 Nerv-IIP 第一至第四阶段纵切的形成过程与当时验收口径。它们用于解释平台控制面如何逐步形成，不是当前实施计划、推荐命令或能力状态。

- [`first.md`](first.md)：Connector Host → AppHub → Gateway 的首批接入查询链路。
- [`second-ops.md`](second-ops.md)：低风险运维动作、领取、结果与审计闭环。
- [`third-console.md`](third-console.md)：Gateway OpenAPI、生成客户端与 Console 消费链路。
- [`fourth-real-infra.md`](fourth-real-infra.md)：真实基础设施与平台 AppHost 的阶段验收。

当前命令、服务边界和验证入口必须从代码、脚本帮助、当前 Architecture、Runbook 与 CI 配置核实。旧 Architecture 文件名只保留迁移兼容导航，不能继续追加阶段进度。
