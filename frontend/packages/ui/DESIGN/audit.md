# 设计系统审计：级联层引导

## 执行摘要

NvUI 的令牌、SFC 层包裹和 shadcn 隔离规则已经建立，但宿主入口未保证在组件模块前加载全局层顺序。真实浏览器中，Screen 的 `NvScreenPanel` 源码内边距 `17px 20px` 计算为 `0px`，标题外边距 `12px` 计算为 `0px`；相同加载模式存在于 PC、Mobile、Touch、Screen 的全部五个宿主。修复责任位于宿主引导与跨宿主契约，不应逐组件提权。

## 路线图

### 0–30 天

1. 在五个宿主入口修复加载顺序。
2. 扩展设计系统契约，同时检查 CSS 内部层顺序与 JS 入口顺序。
3. 用 Screen、PC、Mobile 真实浏览器计算样式验证跨表面结果。

### 31–60 天

无需额外迁移；持续由现有契约测试阻止回退。

### 61–90 天

无需新增组件或令牌。

## 验证证据

- 测试驱动开发（TDD）：入口顺序契约在修复前对五个宿主全部失败；移动导入后转绿。评审补充的注释伪装用例先失败，移除注释后首语句门禁完成，23/23 通过。
- Screen 模拟：`/`、`/factory`、`/workshop/WS-ASSY`、`/line`、`/line/LN-ASSY-1`、`/equipment`、`/warehouse`、`/quality` 均在 1920×1080 下无滚动、无面板裁切、无零内边距；大尺寸 SVG 图表均含绘制标记。
- Screen 留白：`NvScreenPanel` 为 `17px 20px`，标题外边距为 `12px`，状态标签为 `0px 9px`；层顺序样式索引为 0，ScreenPanel 样式索引为 45。
- PC：`NvDescriptions` 带边框单元格为 `10px 14px`；层顺序样式索引为 0，组件样式索引为 19。
- Mobile：`NvMobileGrid` 项为 `14px 4px`、间距为 `8px`；层顺序样式索引为 0，组件样式索引为 627。
- Screen 真实环境：未登录访问 `/factory` 正确进入 `/login`，层顺序样式索引为 0，登录样式索引为 608，页面仍为 1920×1080 且无滚动。
- 包门禁：UI 382 个测试、UI Mobile 61 个测试、Screen 172 个测试、Console 141 个测试、Business Console 1019 个测试、PDA 340 个测试均通过；五个宿主生产构建通过。

## 假设与缺口

- 本审计聚焦级联层引导，不是完整的视觉、无障碍或 Figma 对齐审计。
- 组件库源文件未发现需要逐件修复的留白定义；最终判断以构建产物和真实浏览器计算样式为准。
