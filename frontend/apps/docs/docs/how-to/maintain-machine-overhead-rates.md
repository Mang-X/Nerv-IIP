# 维护机器制造费用率

财务人员在 `/erp/finance/machine-overhead-rates`（经营管理 ▸ 财务 ▸ 机器制造费用率）按会计期间为工作中心维护机器制造费用率。带设备的工序完工结算时，按完工日期所在的会计期间取该工作中心的当前修订；该期间没有修订时，机器费用无法结算。系统不预置费率，每个会计期间开始前需逐个工作中心录入，不产生机器费用的工作中心也要录入一条“不适用”。

1. 选择工作中心，确认会计期间（默认本月，如 `2026-09`，可改为其它期间后按回车或移开光标）。页面显示本期费率、正常产能与修订版本，以及下方的全部修订。
2. 点击“新增修订”（需要财务维护权限），选择“适用”或“不适用”。
   - 适用：填写固定费用预算、变动费用预算（至少一项为正数）和正常产能机器小时。每机器小时费率 = 预算 ÷ 正常产能机器小时，保存后由系统计算。
   - 不适用：该工作中心本期不计机器制造费用，无需填写预算与产能。
3. 填写修订原因，保存。首个修订确定币种，之后的修订（含其它期间）沿用该币种，不能更改。本期已有修订时币种自动锁定；在新期间首次录入时，请填写与以往期间相同的币种，否则保存会提示币种已固定。
4. 修订只追加，不修改、不删除。同一期间版本最高的显示为“当前生效”，其余显示“已被新修订取代”。
5. 保存提示会计期间不存在时，需先由财务开立该会计期间。
6. 补录前已经失败的机器费用结算记在运维的失败消息中（显示“去补充机器制造费用率”）。补录只作用于之后的结算，已失败的结算不会自动重算。

结算后的预定分配与月度差异核对见[核对机器制造费用](/how-to/check-machine-overhead)。
