# 核对工单成本差异

在经营管理 → 财务 → 工单成本差异中，输入工单编号并查询。

1. 对照实际人工工时和金额、标准人工工时和金额。实际人工使用工序结算时冻结的费率，不等同工资实发金额。
2. 核对效率差异：实际减标准，正数为不利、负数为有利、零为无差异。没有标准基准时，按页面提示核对产出速率与覆盖报工；空值不代表零。
3. 单独核对累计成本、已资本化金额及二者差额。资本化差额不是人工效率差异。
4. 在工序人工明细中展开“费率与覆盖报工”，核对结算版本、费率版本、报工数量、理论速率和冲销关系。冲销后重新查询；未重新结算时不会继续展示旧人工结算。
5. 机器工时单独呈现。未启用机器成本时不显示零金额；已启用时显示预定分配，可进入[机器制造费用核对](./check-machine-overhead.md)继续检查。

各金额均按显示币种核对。人工费率差异显示不适用时，表示尚未建立实际工资费率，不能把它当作无差异。
