# 维护工作中心人工费率

财务人员在 `/erp/finance/work-center-cost-rates` 为工作中心维护人工费率。工序完工结算时按完工时间所在的有效修订计价；没有有效修订时，报工无法计算人工成本，完工入库会停在待入库。系统不预置费率，新部署上线前需逐个工作中心录入。

1. 选择工作中心，查看当前有效费率、生效期间和修订版本，以及下方的全部修订。
2. 点击“新增修订”（需要财务维护权限），填写每小时费率、生效日期和修订原因，保存。生效日期按本地零点起算。
3. 首个修订确定币种，之后的修订沿用该币种，不能更改。
4. 修订只追加，不修改、不删除。多个修订同时覆盖当前时间时，版本最高的为“当前生效”，其余显示“已被新修订取代”；尚未到生效日期的显示“未到生效时间”。
