# 认领与关闭安灯呼叫

班组长、设备、质量和工艺响应人可从 MES 的「执行与齐套 → 安灯响应」进入 `/mes/andon`。

1. 在「待响应」队列查看需要响应的呼叫，按缺料、设备、质量、工艺分类或工作中心编号筛选。
2. 核对来源工单、工序和发起时间，点击「认领」。响应人由当前登录账号确定，认领即记录首次响应。
3. 选择「待响应与处理中」查看尚未关闭的呼叫。点击来源工序编号可进入工单详情，目标行标有「来源工序」。
4. 处理完成后，由认领人点击「关闭呼叫」。关闭后的呼叫仍可在「全部呼叫」中查阅。

读取页面需要工序读取权限，认领与关闭需要工序管理权限；返回工单详情还需要工单读取权限。实际可操作范围由账号权限和真实作业关系共同决定。

「未响应」表示尚无首次认领记录，不等于响应时长为零。「已升级」展示已发生的升级时间与接收人，升级不会自动认领、关闭或暂停工序。

如果其他人员已先认领，系统提示认领失败并刷新队列，请按刷新后的响应人继续协同。页面加载失败时点击「重新加载」；写入失败会显示失败提示，不表示已完成操作。可随时点击「刷新」读取最新状态。
