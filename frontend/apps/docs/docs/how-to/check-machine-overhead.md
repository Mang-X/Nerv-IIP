# 核对机器制造费用

财务人员在 `/erp/finance/machine-overhead` 核对工单机器费用与工作中心月度分配差异。

1. 输入工单编号，点击“查询工单”，核对机器实绩工时与固定、变动预定分配额。
2. 展开工序行的“结算追溯”，查看费率期间和版本、结算编号和版本，并与来源记录核对。
3. 输入会计期间；需要聚焦单个工作中心时，再填写工作中心编号。点击“查询月度差异”，逐行核对币种、实际池与已分配额。
4. 遇到“不可用”时，按显示的原因补齐事实或重新结算／对账。冲销后刷新工单费用，复核有效结算，不沿用旧金额。

各状态、预定分配及正负差异的含义见[机器预定分配与月度差异](/explanation/machine-overhead)。
