# 计划员：第一周路径

计划员把需求变成可执行的生产计划。第一周先走通下面 5 条路径，每条路径都以一个业务结果收尾。
状态口径见[按角色入门](/roles/)。

点击顶部「制造执行」会进入当前账号首个有权访问的域内页面；没有生产驾驶舱权限时仍可从已授权的工单等页面继续核对，不需要申请驾驶舱权限。

已承接为工单的计划建议可直接点击工单号进入详情（需要工单读取权限）。带来源的计划入口会定位原建议及其所属运行；普通入口仍先显示需求池。工单详情中的「返回来源建议」按真实来源定位原建议，需具备建议读取权限。计划员在详情核对工序状态、计划与已完成数量、工作中心及来源摘要；报工、收料、检验和交接由各授权岗位接续。报工记录、完工入库、质量检验及缺料库存核对入口按目标权限显示，不因查看工单而扩权。

在排产工作台的草案表格中，先核对每道工序显示的工厂及其时区，再编辑开始/结束时间。输入按工厂时间解释，上海与 UTC 浏览器使用相同配置；无操作保存不会移动工序。时区未就绪时草案会保留，时间输入暂不可用。该读取只覆盖当前有权访问的方案，不要求主数据目录权限；甘特和详情的统一工厂时间仍待接续。

## 第一周路径

| #   | 路径（页面操作串）                                                                                                                                                                  | 业务结果                                                          | 状态                                                                                                                                                                                                          |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 在 `/planning` 查看 ERP 销售订单自动形成的需求或维护手工需求，随后运行 MRP                                                                                                          | 得到可处理的计划建议与需求追溯（pegging），并可按来源订单钻取 ERP | ✅ 可用；订单变更/取消按版本收敛，取消需求不进入后续 MRP                                                                                                                                                      |
| 2   | 在 `/planning` 接受计划建议，再到 `/mes/plans` 跟踪生产计划                                                                                                                         | 建议进入 MES 可消费的生产计划                                     | ✅ 可用                                                                                                                                                                                                       |
| 3   | 在 `/scheduling` 用表格和只读资源甘特查看排产结果与产线负载；点甘特上的工序块在右侧并排看该工序详情，点「方案明细」看整方案；在当前页按日期与工作中心打印日排程单或下载完整方案 CSV | 核查工序时间、资源、冲突与未排原因                                | 🟡 部分可用：只读甘特、工序详情、方案明细和发布门禁已交付；齐套情况请到「领料与齐套」页核对，拖拽改期/改派、自动重排、显式撤销页面动作仍待后续交互交付（[#78](https://github.com/Mang-X/Nerv-IIP/issues/78)） |
| 4   | 在 `/planning` 处理提前/延后/取消类异常建议                                                                                                                                         | 计划收货与最新需求重新对齐                                        | 🟡 部分可用：MRP 例外消息面板未交付（[#805](https://github.com/Mang-X/Nerv-IIP/issues/805)）                                                                                                                  |
| 5   | 把采购类建议转成采购申请与采购订单                                                                                                                                                  | MRP 建议进入采购执行                                              | ⛔ 缺口：采购申请到采购订单的转化流程未打通（[#711](https://github.com/Mang-X/Nerv-IIP/issues/711)）                                                                                                          |
