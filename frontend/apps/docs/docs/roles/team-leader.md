# 班组长：第一周路径

班组长把工单变成合格的完工产出。第一周先走通下面 7 条路径，每条路径都以一个业务结果收尾。
状态口径见[按角色入门](/roles/)。

## 工序与报工重试

工序开始、暂停、恢复和完成在同一次失败或超时后复用意图键，服务端回放首次确认的状态和变更时间，不会重复推进生命周期；同一键改用于另一工序或动作会被拒绝。报工请求返回“已受理”后，仍须按回执中的报工 GET 路径读取权威记录，确认报工编号、数量和状态；HTTP 200 或页面乐观状态不代表报工已经确认。

### 复检重放与后续轮次

复检请求以路由中的前置检验记录 ID 作为幂等身份。同一前置记录被重复提交时，服务返回已存在的直接后继，不用新载荷覆盖既有检验事实。若最新一次复检仍未通过并需要继续复检，调用方必须改用该最新未通过轮次的记录 ID；继续提交原始首检 ID 只会重放第 2 轮。
