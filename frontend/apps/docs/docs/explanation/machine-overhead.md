# 机器预定分配与月度差异

工单机器制造费用是按冻结费率计算的**预定分配**，不是已核定实际机器成本。固定、变动分配额及合计与对应的费率期间、费率版本和结算来源一起保留，便于追溯。

月度差异为工作中心实际费用池减已分配额：正数表示未分配，负数表示多分配，零表示无差异。应按各行币种核对，不跨币种相加。

“不适用”表示没有适用的机器制造费用；“不可用”表示当前尚不能形成有效核算结论，并附原因；明确零显示数值零。冲销会改变有效结算范围，旧金额不能继续作为当前工单结论。已被替代的月度对账记录仅供追溯，不作为当前关账依据。

查询步骤见[核对机器制造费用](/how-to/check-machine-overhead)。
